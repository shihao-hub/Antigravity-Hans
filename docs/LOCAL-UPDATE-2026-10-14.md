# 普通版 2.23.0 本地更新

本次只针对 Antigravity 普通版；IDE 静态补丁、语言配置及专属词条没有修改。

词库从 806 条增加到 1300 条。新增的普通版控件/设置文案，逐条对照本机 2.23.0 实际加载的前端 `main.js`；另新增普通版 WSL 启动浮窗与退出确认文案，并适配两条含发行版名称的动态状态。前端资源 SHA-256：

```
867d1990b61d87f4b9ff8c5ecb1551c8688135267f32e56e02563f2d3e78fd68
```

覆盖代码搜索、对话分屏、钩子管理、沙盒策略、统筹助手、通知、Git 操作状态和工作区选择。资源中的文案可能由功能开关控制，新增词条不意味着这些功能对所有账号都可见。未将原应用的资源文件复制到仓库。

根据用户截图补齐执行策略菜单中的 `Auto (Preview)` → `自动（预览）`；其说明 `Automatically decide if commands run.` 已收录为 `自动判断是否运行命令。`。更新独立脚本的默认内容版本标记，并重建三平台程序，使内嵌词库包含此次补充。已通过 JavaScript 语法、行为回归、词库 lint 和这两条文案的直接匹配检查；没有对用户正在运行的应用进行注入或重启。

根据第二张截图补齐侧边栏显示菜单及相关子菜单：排序方式、显示、仅显示已归档、全部标为已读、自定义顺序、仅显示未读、定时任务、标记，以及工作区/项目与工作树的显示选项。补齐历史页停用提示，并按图标两侧的实际文本节点分别翻译搜索及归档指引。此次新增 15 条文案，均对照普通版前端资源；已检查菜单文案、分段指引及重复处理结果，并重新构建三平台程序。

修复第三张截图中的 `Last 7 天` 半翻译：补充普通版前端实际包含的 `Last 7 days` → `最近 7 天`，并让完整时间筛选标签匹配先于通用时间单位转换。新版能重新处理旧词库留下的半翻译文本，也支持天数变化。回归检查覆盖初始翻译、半翻译修复、重复处理、空白保留，以及权限目标中的同名命令/路径原文保持不变。

安全与启动修复：

- 权限模板只翻译固定文案，保留命令、路径、URL、工具名和规则内容。二次观察同一文本也不改写目标；未知权限模板保留原文。
- macOS 快捷方式正确引用含空格、引号、美元符号、反引号或换行的路径。随机创建权限探针，生成文件采用受目录边界限制的原子替换。普通版启动由监视器负责，重复点击时只激活已有普通版窗口，避免原版启动与调试启动争抢单实例。
- 正常退出取消、被拒绝或超时后中止重启，避免自动强杀造成未保存内容丢失。
- 调试端点复用须确认实际监听进程属于目标应用，并验证页面与 WebSocket 地址。普通版 2.23.0 默认启用的随机调试端口也可复用。
- CDP 禁止跨主机重定向及环境代理，限制响应/消息大小和写入、握手超时。后台检查同一页面时不再叠加验证任务。
- 单实例保护改为持有系统文件锁；PID 记录增加创建时间和可执行路径，避免 PID 复用误判。兼容不同路径的旧版工具时检查 Go 模块身份，不依赖进程名子串。锁文件保持同一文件身份，不通过删除锁文件释放。
- 外部词库在打开前检查类型和大小，读取后复核文件身份并限制读取量。显式信任也不能绕过这些限制。Unix 检查属主与写权限，Windows 自动使用内嵌词库，外部脚本须显式信任。
- 词库内容指纹用于识别更新；新版脚本能清理旧观察器和待处理任务。更早版本若没有清理入口，会提示重新加载窗口后更新，避免旧规则继续修改权限提示。
- 修复词库 lint 的单词边界转义，并增加权限极性、动态模板、过滤范围和更新行为回归测试。

依赖更新：`gopsutil/v4 4.26.9`、`golang.org/x/sys 0.49.0`，间接依赖随上游依赖树更新。没有引入 IDE 配置解析的新依赖。

本地验证包含 Go 单元/跨进程测试及竞态检查、`go vet`、JavaScript 语法和 7 组行为测试、词库 lint、三组发布平台依赖扫描、三平台编译，以及对实际普通版 CDP 端点的只读检查。没有重启用户应用或更改它的安装资源；没有对 Windows 实际应用界面做端到端验证。

CI 已配置 Ubuntu、macOS、Windows 原生测试和漏洞扫描。发布作业等待这组检查全部通过，并提供 SHA-256 校验清单；这些配置未推送执行。

本次产物位于 `dist/`。版本文件 `VERSION` 保持原值，未触发发版，也未推送 GitHub。运行新版前先结束旧监视器；如日志提示旧脚本没有清理入口，重新加载当前普通版窗口再运行。
